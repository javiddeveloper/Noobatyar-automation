# آیکن و هویت بصری نوبت‌یار

## ایده‌ی طراحی

حلقه‌ی بازِ بالا هم‌زمان سه چیز را می‌گوید:

1. **صفحه‌ی ساعت** — زبان جهانی «نوبت و زمان».
2. **کاسه‌ی حرف «ن»** — اولین حرف «نوبت». نقطه‌ی بالای حلقه همان نقطه‌ی «ن» است.
3. **نقطه‌ی کهربایی** = «نوبت بعدی / نوبت شما»؛ تنها رنگ مکمل در کل هویت.

تیک داخل حلقه یعنی **نوبت تأیید شد**، و هم‌زمان حس عقربه‌های ساعت را می‌دهد.

رنگ اصلی از خود محصول گرفته شده: `--color-primary: #8b5cf6` در
[`front_client/app/globals.css`](../front_client/app/globals.css).

## فایل‌ها

### SVG (منبع اصلی — همیشه این‌ها را ویرایش کن، نه PNG‌ها)

| فایل | کاربرد |
|---|---|
| `noobatyar-icon.svg` | آیکن اصلی، گوشه‌گرد. وب، فاوآیکن، PWA |
| `noobatyar-icon-square.svg` | مربع کامل بدون گوشه‌گردی. اندروید adaptive و iOS که خودشان ماسک می‌زنند |
| `noobatyar-mark.svg` | فقط نشان، زمینه شفاف، با `currentColor` |
| `noobatyar-favicon.svg` | نسخه‌ی ساده‌شده برای ۱۶ تا ۳۲ پیکسل |

### PNG و WebP

در `png/` و `webp/`:

- `noobatyar-icon-{16…1024}` — آیکن کامل (زیر ۲۰px خودکار از نسخه‌ی ساده استفاده شده)
- `noobatyar-square-{192,432,512,1024}` — برای adaptive icon اندروید
- `noobatyar-mark-ink-{128…1024}` — نشان جوهری برای زمینه‌ی روشن
- `noobatyar-mark-white-{128…1024}` — نشان سفید برای زمینه‌ی تیره

همه‌ی WebPها **lossless** هستند؛ برای گرافیک تخت با لبه‌ی تیز، lossy لبه‌ها را کثیف می‌کند.

## نکته‌های استفاده

- **زیر ۲۰ پیکسل** حتماً `noobatyar-favicon.svg` را استفاده کن. تیکِ آیکن کامل در آن اندازه با حلقه یکی می‌شود و به هم می‌ریزد.
- `noobatyar-mark.svg` از `currentColor` استفاده می‌کند؛ رنگ را با `color` روی والد ست کن. برای رستر کردنِ مستقیم، رنگ را صریح جایگزین کن — وگرنه librsvg آن را سیاه می‌کند.
- **فضای امن:** حداقل به اندازه‌ی ۱۰٪ عرض آیکن دور تا دورش فضای خالی بگذار.
- نشان را نکش/کج نکن، گرادیان را با رنگ‌های دیگر عوض نکن، و نقطه‌ی کهربایی را بنفش نکن — همان تنها لهجه‌ی رنگی هویت است.

## اعمال روی اپلیکیشن‌ها

هر دو اسکریپت با `sharp` کار می‌کنند که داخل `front_client/node_modules` هست.

ساخت فایل‌های رستر داخل خود `brand/`:

```bash
NODE_PATH=front_client/node_modules node brand/build-icons.js
```

پخش آیکن روی همه‌ی اپ‌ها (وب، اندروید ×۲، iOS ×۲) — ۵۴ فایل:

```bash
NODE_PATH=front_client/node_modules node brand/apply-to-apps.js
```

هر بار که SVGها را عوض کردی، دومی را دوباره اجرا کن. همه‌ی خروجی‌ها بازنویسی می‌شوند، پس SVGها تنها منبع حقیقت می‌مانند.

### فایل‌های مخصوص اندروید (`brand/android/`)

| فایل | چرا جداست |
|---|---|
| `ic_launcher_background.svg` | لایه‌ی پس‌زمینه‌ی adaptive — فقط گرادیان. لانچر این لایه را مستقل از فورگراند حرکت می‌دهد، پس هیچ نقشی نباید رویش باشد |
| `ic_launcher_foreground.svg` | لایه‌ی رویی adaptive — شفاف، نشان با مقیاس ۰٫۷۸ داخل ناحیه‌ی امن |
| `ic_launcher_round.svg` | آیکن گرد قدیمی؛ دایره از قبل روی خودش ماسک شده چون بعداً چیزی ماسکش نمی‌کند |
| `ic_notification.svg` | آیکن نوتیفیکیشن — **فقط سیلوئت سفید**. اندروید رنگ را دور می‌ریزد و آیکن را از کانال آلفا بازسازی می‌کند؛ اگر آیکن رنگیِ کامل بدهی، یک مربع سفید توپر نشان می‌دهد |

### دو تا `main_icon.png` که یکی نیستند

در هر اپ موبایل دو فایل هم‌نام وجود دارد که دو سیستم منبع جدا آن‌ها را می‌خوانند:

- `commonMain/composeResources/drawable/main_icon.png` → `Res.drawable.main_icon`، در `SettingsScreen` و `AboutUsScreen` مستقیم کشیده می‌شود ← **آیکن رنگی کامل**
- `androidMain/res/drawable/main_icon.png` → `R.drawable.main_icon`، فقط در `ReminderReceiver` به‌عنوان `setSmallIcon` ← **سیلوئت سفید**

اسکریپت هرکدام را با نسخه‌ی درست پر می‌کند. جابه‌جا کردنشان یعنی نوتیفیکیشن‌ها مربع سفید نشان بدهند.
